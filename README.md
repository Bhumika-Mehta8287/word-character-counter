# 📝 Word & Character Counter

A lightweight and responsive web app that allows users to count the number of words and characters in a given text. Built using HTML, CSS, and JavaScript, this tool is perfect for writers, bloggers, and students who want to track their writing metrics in real-time.

---

## 🔍 Features
- Real-time word and character counting
- Clear text button to reset input
- Simple and responsive UI design
- Easy to use in any browser

---

## 🚀 Technologies Used
- **HTML** for the structure
- **CSS** for styling and layout
- **JavaScript** for real-time functionality
